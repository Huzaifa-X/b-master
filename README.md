# Super Admin Dashboard - AI SaaS Platform

A comprehensive, enterprise-grade admin dashboard for managing an AI-powered SaaS platform. Built with Next.js 14+, TypeScript, and modern UI components.

## 🚀 Features

### Core Modules

- **📊 Dashboard Overview** - Real-time metrics, analytics charts, and activity feeds
- **📝 Prompt Management** - Create, edit, and manage AI system prompts with version control
- **👥 User Management** - Complete user administration with role-based access control
- **📈 Analytics Dashboard** - Comprehensive AI usage analytics with detailed reporting
- **💬 Messages Monitoring** - Quality control interface for user messages and AI responses
- **🎯 Banner Management** - Marketing banner creation with scheduling and targeting
- **💳 Plan Management** - Subscription plan administration with pricing tiers

### Design Features

- ✨ Modern, responsive UI with shadcn/ui components
- 🌓 Dark mode support with next-themes
- 📱 Mobile-friendly collapsible sidebar
- 🎨 Beautiful charts and visualizations with Recharts
- ⚡ Fast, optimized performance with Next.js 14 App Router
- 🔍 Advanced data tables with search, filter, and pagination
- 🎭 Smooth animations and transitions

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router, TypeScript)
- **UI Components**: shadcn/ui
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Tables**: TanStack Table
- **Forms**: React Hook Form + Zod
- **State Management**: Zustand
- **Theme**: next-themes

## 📦 Installation

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Run the development server**
   ```bash
   npm run dev
   ```

3. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
